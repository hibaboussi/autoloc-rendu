# AutoLoc API

Projet Spring Boot / Maven créé dans le cadre de l'atelier 1.

## Stack
- Java 17
- Spring Boot 3.3.5
- Spring Data JPA
- MySQL
- Lombok
- Maven

## Configuration
Le fichier `src/main/resources/application.properties` contient la configuration JDBC MySQL et les options Hibernate.

## Entités créées
- Vehicule
- Agence
- Client
- Employe
- Equipement
- Reservation
- Contrat
- Paiement
- Maintenance

## Démarrage
```bash
mvn spring-boot:run
```
